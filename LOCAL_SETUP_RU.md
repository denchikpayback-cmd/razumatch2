# Запуск Razumatch локально (Windows, Node.js 24)

1. Распакуй проект в `C:\My_projects\Razumatch` и открой папку в VS Code.
2. Установи зависимости: `pnpm install --frozen-lockfile`.
3. Запусти `pnpm dev`. **Оставь этот терминал работающим.**
4. Открой `http://127.0.0.1:5173/`. Первое открытие до настройки БД может показать ошибку — это ожидаемо.
5. В VS Code открой **второй** терминал в той же папке и выполни `pnpm db:local:init`. Команда создаст таблицы в локальном D1-файле Vinext и сделает резервную копию. Если база уже существует, пользователи сохранятся.
6. Обнови страницу браузера `Ctrl+Shift+R` и зарегистрируй тестового пользователя.
7. Чтобы назначить владельца в локальном окружении, создай `.dev.vars` рядом с `package.json`, напиши `ADMIN_SETUP_TOKEN=твой_длинный_случайный_секрет` и перезапусти `pnpm dev`.

Если браузер пишет `Failed to fetch`, проверь, что `pnpm dev` не остановлен и в терминале напечатан локальный адрес.

**Важно:** не запускай миграции через отдельный `wrangler.local.json`, не удаляй `.wrangler` и не направляй миграции в удалённую базу. Эта команда предназначена только для локальной среды Vinext.
