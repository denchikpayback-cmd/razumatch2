# разуMATCH

Знакомства для студентов и выпускников МГУТУ. Vinext / Cloudflare Worker, D1 для базы, R2 для файлов. Исходники: https://github.com/KonstantinVaskov/razumatch (приватный репозиторий).

## Регистрация и вход

Новые пользователи регистрируются на сайте по email и паролю. Аккаунт ChatGPT не требуется. Email нормализуется, но не подтверждается письмом: почтовый провайдер пока не подключён. Пароль — 12–128 символов. В базе хранится scrypt-хеш (N=16384, r=8, p=5) с индивидуальной случайной солью. При регистрации выдаётся личный код восстановления; в базе хранится только его SHA-256-хеш.

Сессия — случайный 256-битный токен, в базе хранится его хеш; cookie `__Host-razumatch-session` имеет Secure, HttpOnly, SameSite=Lax, Path=/ и срок до 30 дней. Выход отзывает текущую сессию. Восстановление по email и личному коду меняет пароль, перевыпускает код и отзывает все старые сессии. Без пароля и сохранённого кода автоматического восстановления нет. Владелец хостинга может выпустить одноразовый адресный код восстановления: секрет ACCOUNT_RECOVERY_GRANT содержит email, userId, expectedRecoveryHash (текущий recovery_hash), tokenHash (SHA-256 случайного кода), issuedAt и expiresAt в миллисекундах. Максимальный срок — 24 часа. Значения и сам код не сохраняются в репозитории. Код вводится в обычной форме восстановления; смена recovery_hash атомарно делает выданный код недействительным, отзывает прежние сессии и сохраняет профиль и права. После использования или истечения срока секрет нужно удалить из настроек хостинга и применить конфигурацию публикацией. Введены серверные ограничения количества попыток по хешу email и доверенному edge IP. Защита от CSRF проверяет Origin для авторизации и запросов изменения данных.

## Перенос прежней анкеты

В регистрации открыть «У меня уже была анкета» и выбрать перенос. Для переноса один раз требуется подтвердить прежний вход; это необязательно для новых пользователей. Стабильный старый ID сохраняется вместе с анкетой, медиа, сообщениями и правами владельца. По одному совпадению email аккаунты не объединяются. Смена способа входа обновляет уведомление до версии 2026-10-26-v3; согласие на исследования не переносится автоматически.

## Возможности

- Анкета и необязательные музыка, фильмы, книги, интересы, ценности, стиль общения и выбор общежития.
- Объяснимый подбор по общим интересам и целям. Внешняя ИИ-модель не подключена.
- Реальные взаимные симпатии, сообщения, фото, видео и вложения. Обновление чата — раз в 4 секунды.
- Проверка прав для переписок, файлов, поддержки и администрирования на сервере.
- Общая выдача участников от 16 лет без разделения на до и после 18 лет. Возраст указан в анкете и пока сообщается самим пользователем. Чат открывается после взаимной симпатии; блокировки действуют независимо от возраста.
- Блокировки, жалобы, поддержка с ответами владельца, тёмная и светлая темы.
- Тестовых анкет и автоматических собеседников нет.

## Владелец и поддержка

«Поддержка» → «Я владелец проекта»: первый ввод серверного кода ADMIN_SETUP_TOKEN привязывает владельца. Код хранится только в настройках хостинга. Если владелец уже назначен прежнему аккаунту, нужно переносить именно старый аккаунт, а не создавать дубликат.

Владелец видит обращения всех участников, отвечает на них и закрывает. Открытый список обращений обновляется раз в 15 секунд. Есть статистика и просмотр жалоб. Email- и push-уведомления не подключены. Личные переписки пользователей не доступны через кабинет владельца.

«Поддержка» → «Контакты проекта»: заполнить реальное ФИО/название оператора и email; они будут опубликованы в уведомлении об использовании данных.

## Использование данных

Перед регистрацией и использованием знакомств необходимо подтвердить обработку для работы сервиса. Исследовательское согласие отдельное, добровольное, выключено по умолчанию и доступно только пользователям 18+. Уведомление: `/ui/privacy.html`, версия 2026-10-26-v3. Версия, время подтверждения и изменения сохраняются в privacy_preferences и privacy_events.

Владелец может вручную скачать конфиденциальный JSON только согласившихся совершеннолетних: случайный participant, interests, music, films, books, hobbies и goal. Имена, контакты, возраст, город, общежитие, группа, переписки, поддержка и медиа исключены. Это псевдонимизация, а не гарантия анонимности. Выгрузки записываются в export_audit. Отзыв немедленно исключает пользователя из будущих выгрузок; ранее скачанные копии требуют ручного удаления при обращении. Никакого автоматического обучения и передачи ИИ-провайдерам нет.

Удаление аккаунта удаляет профиль, медиа, сообщения, симпатии, обращения, согласия, парольные данные и сессии. Жалобы и административный журнал сохраняются отдельно.

## Медиа и общежития

Изображения JPG/PNG/WebP/GIF до 10 МБ, видео MP4/WebM/MOV до 50 МБ, в чатах также PDF до 10 МБ. Всего до 100 файлов или 300 МБ на аккаунт. MOV воспроизводится не всеми браузерами. Главное фото — первое изображение профиля.

Общежитие — необязательное поле residence: klinskaya, orenburgskaya, narodnogo, none или пустое значение. Клинская, 8Б и Оренбургская, 20, корп. 3: https://www.mgutm.ru/student/student-general/dormitory/ . Народного Ополчения упоминается в отчёте университета о мероприятии 28.02.2025: https://mgutm.ru/wp-content/uploads/2025/04/otchet-o-samoobsledovanii_moskva-2024.pdf . Номер дома третьего общежития не указан без подтверждённого источника. Номера комнат не собираются.

## Разработка и GitHub

Node.js 24 и pnpm версии из packageManager. Установка: `pnpm install --frozen-lockfile`. Проверки:

```sh
node tests/auth.cjs
node tests/api.cjs
node tests/navigation.cjs
pnpm exec tsc --noEmit
```

GitHub Actions запускает их при push в main и pull request. Тесты используют настоящую SQLite и настоящий scrypt с эмуляцией D1/R2; они не заменяют проверки пользовательских сценариев на опубликованном сайте.

Код API: `app/api/[...path]/route.ts`, авторизация: `app/site-auth.ts`, интерфейс: `public/ui/`, схема: `db/schema.ts`, неизменяемые миграции: `drizzle/`. После изменения схемы выполнить `pnpm run db:generate`.

Для публикации использовать Sites workflow и build-site.mjs. D1 (DB), R2 (BUCKET) и секреты не включены в репозиторий. GitHub Pages этот backend не поддерживает. Автопубликация из GitHub не настроена. Основная страница публична, но API анкет, переписок и файлов требует собственной сессии. Прежняя интеграция ChatGPT сохранена только для необязательного переноса существующих аккаунтов.

## Что ещё требует решения владельца

Реальные контакты оператора, модерация, сроки хранения жалоб и административных журналов, работа с запросами удаления скачанных исследовательских копий. Принадлежность к вузу и возраст документально не проверяются. Юридическая проверка условий обработки данных и автоматические бэкапы отдельно не выполнены. Рекламные платежи и реальная ИИ-модель не подключены.

## Разделы и переписки

Общая выдача больше не ограничивается полом и прежним параметром soughtGender. Разделы «Все», «Дружба», «Отношения» переключаются через GET /api/discover?intent=friendship|relationship. В анкете intentions содержит friendship, relationship или оба значения. Старое goal автоматически интерпретируется при чтении, без удаления данных; при сохранении обновляется совместимое текстовое поле goal. В анкетах и чатах показываются цветные метки. Блокировки, заполненная анкета, актуальное уведомление и взаимный лайк для чатов сохраняются.

Нижняя навигация доступна на телефоне и компьютере. Переписка: поиск по диалогам, сохранение текста черновика внутри текущей вкладки, Enter для отправки на компьютере, Shift+Enter для переноса строки, обычный перенос на телефоне. Вложения выбираются через скрепку, вставку изображения или перетаскивание, показываются локально перед загрузкой. Загрузка через XHR отображает прогресс, успешные файлы не дублируются при повторе неудачных. Файлы чата отправляются только вместе с нажатием отправки; неотправленные вложения удаляются при выходе из чата. Фотографии профиля публикуются после явного подтверждения. Данные и ограничения размеров хранятся и проверяются на сервере.

## Кабинет владельца: участники

В разделе «Поддержка» владелец видит кнопку «Пользователи». Она открывает список с поиском (имя, email, ID), пагинацией и детальными анкетами. API `GET /api/admin/users` и `GET /api/admin/users/:id` проверяют `admin_user` на сервере; обычным участникам возвращается 403. В деталях доступны поля анкеты, согласия и агрегированные показатели, но не хеши паролей, токены сессий или содержимое личных сообщений. Новые миграции БД не требуются.


## Административный просмотр диалогов (2026-10-27-v4)

В карточке пользователя добавлена кнопка «Просмотреть диалоги». Владелец с серверной проверкой прав может читать сообщения в режиме только для чтения, **после подтверждения актуального уведомления обоими участниками**. Старое согласие не открывает доступ. Просмотр каждой страницы сообщений фиксируется в `admin_chat_audit`; содержимое сообщений в журнал не копируется. Вложения не раскрываются через новый endpoint. Постраничная выдача ограничена 100 сообщениями.

**Перед публикацией:** примените миграцию `drizzle/0005_admin_chat_audit.sql` к рабочей D1; убедитесь, что новые и существующие пользователи видят обновлённое уведомление `/ui/privacy.html` и подтверждают его. Не выдавайте права владельца сторонним людям. Учтите правовые требования для обработки данных пользователей от 16 лет.
