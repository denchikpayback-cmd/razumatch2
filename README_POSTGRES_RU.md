# RazuMatch + PostgreSQL (Next.js)

Это версия исходного RazuMatch с PostgreSQL вместо Cloudflare D1. Исходный интерфейс и API сохранены; SQL-слой переведён на pg.

## Запуск на Windows

1. Установить Node.js >= 22, pnpm и Docker Desktop.
2. Скопировать `.env.example` в `.env` и `.env.local`. Изменить пароли в обоих файлах (на одинаковые значения для POSTGRES_PASSWORD в .env и DATABASE_URL в .env.local). Для URL-кодирования спецсимволов в пароле используйте percent encoding либо начните с парольной строки только из латинских букв и цифр.
3. `docker compose up -d`
4. `pnpm install --no-frozen-lockfile`
5. `pnpm db:init`
6. `pnpm dev`
7. Открыть http://127.0.0.1:5173. Создать аккаунт; в «Поддержка → Я владелец проекта» ввести `ADMIN_SETUP_TOKEN`.

Данные лежат в PostgreSQL, посмотреть их можно через DBeaver (localhost:5432, БД razumatch). Тестовая локальная БД пуста. Для переноса из D1: `migrate_d1_to_postgres.py` из архива; прочитайте его параметры и сделайте резервную копию перед запуском. Медиа D1/R2 этим скриптом не переносится.

## Важно для публикации

Нужны HTTPS, отдельное S3/R2 для фотографий/видео (пока `.local-uploads`), защищённый PostgreSQL без открытого внешнего порта, секреты через переменные окружения, резервные копии и проверка авторизации. Не выводите хэши паролей в клиентский API.

## Известные ограничения

В среде подготовки не было запущенного PostgreSQL и пакетов npm, поэтому интеграционные тесты с работающей БД не проведены. Рекомендуется сначала выполнить ручные проверки входа, анкет, диалогов и загрузки. Перед полноценной публикацией проведите проверку безопасности и нагрузочный тест.
